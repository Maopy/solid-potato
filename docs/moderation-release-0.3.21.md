# 0.3.21 抖音实时评论规则修复

修复原生评论 Common.create_time 缺失时被判为不可实时处理的问题。当前抖音评论的事件时间位于 ChatMessage.event_time（字段 15），现在以该字段作为缺失公共时间戳时的补充。仍过滤超过 30 秒或未来超过 5 秒的评论；时间完全缺失时仍不参与自动规则，房间身份和原生消息去重检查不变。

关键词回复和定时文案的评论计数恢复使用这些新评论。定时文案仍同时满足 interval_seconds 和 min_comments 才触发；共用回复的关键词仍共享回复冷却。

config 完整继承上一版，包括用户自定义阈值、文案和关键词。抖音需要更新用户脚本并刷新页面；权限范围不变。修复只在前端解码，可更新脚本后继续使用已运行的 0.3.20 后台，无需中断录制。下次启动使用本版目录即可。
