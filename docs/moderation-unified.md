# 统一启动与控制

0.3.13 起，抖音使用 Tampermonkey 用户脚本，视频号使用代理，两个平台共用本机控制台、发送规则和下载列表。双击发布包的“启动场控.command”，在控制台点击“安装 / 更新抖音场控脚本”，安装后刷新任意抖音直播间。每个抖音房间自动出现独立控制卡片，场控默认关闭。

抖音无需场控证书。视频号继续在微信打开直播页并选择相应任务。场控开关控制欢迎、礼物感谢、关键词和定时文案；录制独立操作，关闭场控不会停止录制。关闭场控时取消待处理消息，每条命令只尝试点击发送一次，不等待平台回显；结果不确定只记日志，不重发，也不暂停后续消息。

保留上一版 config，抖音规则仍取自 unified.yml 引用的 douyin-auto.yml。该 URL 只是旧代理模式使用的房间地址，用户脚本可连接任意数字抖音直播间。动态房间分别管理队列和开关，同一抖音账号共享发送限流。

首次安装、配对密钥、兼容限制和故障排查见 [0.3.13 使用说明](moderation-release-0.3.13.md)。后续升级保留发布目录旁 `.live-archive-userscript-key` 和 2025 端口，正常重启无需重新安装脚本；启动后刷新直播页重新连接。

结束时在启动终端按 Ctrl-C，等待录像收尾、代理恢复后退出。旧进程已确认退出时会自动恢复遗留 PID 锁；持有目录锁的正常实例不会被强行终止。

0.3.16 取消发送确认和未确认阻塞，升级时需重新打开视频号直播页，并更新抖音用户脚本后刷新页面。详见 [0.3.16 使用说明](moderation-release-0.3.16.md)。

0.3.17 修复脚本隔离环境的消息接入，支持抖音主站 follow/live、root/live、live 数字房间入口及同页切换。面板新增采集数量和输入框状态。本次升级需要更新脚本以授予页面对象访问；详见 [0.3.17 使用说明](moderation-release-0.3.17.md)。

0.3.18 兼容实际直播的 pb/msg 未压缩消息帧，更新脚本后刷新可清除旧文档解析暂停。详见 [0.3.18 使用说明](moderation-release-0.3.18.md)。

0.3.19 起，两平台直播页面板默认收起为状态按钮，点击展开操作、再次点击标题收起；收起不关闭场控或停止录制。
