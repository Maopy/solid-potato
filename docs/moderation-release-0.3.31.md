# 0.3.31 场控退出恢复系统代理

统一入口 serve 和单房间 probe 在启动时订阅 SIGINT、SIGTERM、SIGHUP。终端关闭或常规终止命令不再绕过退出清理；Windows 保留 Ctrl-C 路径。

收到退出事件后先恢复系统代理，再等待事件排空和录像收尾。收尾行为保留，减少代理仍指向本机端口而退出流程长时间等待造成的断网。

macOS 修改系统代理前启动独立恢复进程，通过私有管道传递本次网络服务、HTTP/HTTPS 原设置和本地端口。恢复进程独立于终端前台进程组：主进程异常退出、被 SIGKILL 或崩溃时，管道 EOF 触发恢复；正常恢复成功后显式撤销恢复进程。启动恢复进程失败时不启用系统代理。无新增 CA 或信任权限。

恢复只处理仍指向本次场控代理地址的 HTTP/HTTPS 字段，保留其他软件或用户运行期间修改的代理。部分启动失败也能恢复已应用的字段。恢复失败保留原快照并允许重试，独立恢复进程最多尝试五次。真实系统命令失败仍可能需要人工处理；同时强杀整个进程树（含恢复进程）、关机断电不保证即时恢复。本版不保存跨重启恢复日志，也无法凭空恢复旧版本已遗失的原设置。

已通过模拟系统命令测试：正常撤销、父进程 SIGKILL、用户后续修改、部分代理应用与原代理保留；单独子进程验证 SIGINT、SIGTERM、SIGHUP。测试未修改真实系统代理或停止实际录像。配置完整继承上一版，已有浏览器脚本无需更新。需退出旧后台、等待录像收尾后使用本版启动入口。
