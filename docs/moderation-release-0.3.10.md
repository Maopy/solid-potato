# 0.3.10 场控与直播录制合并

抖音、视频号直播流录制已接入场控，使用原有场控启动脚本即可。视频号保留原来的“录制直播”和下载任务列表；抖音页面提供“录制直播”“下载任务”，支持暂停、继续和移除。单纯启动场控不录制，点击后才启动 FFmpeg。

场控与录制共用一个进程和代理，避免另启旧监听程序导致端口冲突。礼物感谢、欢迎、关键词回复的操作保持原样。发布包自动继承 0.3.9 的 config，包括关键词回复和之前修改的文案、开关。

停止旧程序后使用本版启动脚本，重新打开直播页，播放直播，再点击录制。需要 FFmpeg。视频一般保存在本版 `data/recordings` 下，按平台与任务分目录；停止或退出时等待 TS 收尾转换为 MP4，移除任务保留已有视频。

可选设置及限制见 [录制说明](moderation-recording.md)，配置示例为 config/recording.example.yml。旧 YAML 无需增加字段。controller 使用顶层 recording 设置。

验证包括组合代理的两个平台页面注入、原场控路由可用、双路录制并行、暂停一路不影响另一路、继续与移除任务、退出收尾以及原评论发送回归。模拟集成不连接真实直播平台；真实媒体收尾另使用本地测试视频验证。
