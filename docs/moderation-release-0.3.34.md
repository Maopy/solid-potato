# 0.3.34 录制状态与暂停继续

统一场控右上角入口加入录制状态圆点：后台任务 downloading 时显示红色，其余状态为灰色。展开后显示实际任务状态，不再使用“已提交录制请求”作为成功提示。等待启动、暂停、失败、连接状态未知分别显示；连接或状态查询失败不保留旧红点。

录制按钮按状态显示“开始录制 / 暂停录制 / 继续录制”。暂停与继续使用同一后台任务，不创建重复录制；下载任务列表中的暂停、继续、删除也会在约一秒内同步到面板。暂停会停止采集并收尾分段，继续重新连接当前任务的直播源，写入同一主播目录的新时间戳分段，不补录暂停期间内容。

后台任务列表补充平台和直播页面作用域，用于刷新页面后恢复状态，避免另一个平台或直播间的录制点亮当前页。视频号再按已加载的主播昵称匹配当前直播；状态依据任务系统，不以请求发送完成推断正在录制。旧后台缺少作用域时，不能可靠匹配的活动任务显示状态未知并提示更新后台。

场控页面移除视频号旧的独立录制按钮和原生信息栏下载图标，保留共享面板与下载任务列表。独立录制工具没有场控 SDK 时仍保留自身入口。

回归覆盖两平台开始、暂停、继续、红灰状态、失败恢复、共享任务作用域和后台录制收尾。模拟测试未向真实直播间发送弹幕或暂停真实录像。配置继承上一版。启动本版后台并重新加载两平台页面后生效；抖音用户脚本需更新到本版。
