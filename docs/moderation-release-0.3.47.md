# 0.3.47 深色场控面板与本地语音识别

语音只保留最近 3 句，面板移除“语音 · 正在听直播”等常规状态标题，有识别文字时直接展示文字。关闭后隐藏语音文本区域；初次等待结果和异常时仍提供提示。不保存历史转写。

场控和语音按钮统一为状态圆点及固定两字标签，与录制、点赞风格一致。开启绿色、关闭灰色，操作提示放入悬停说明。

收起后仅显示场控状态圆点、录制状态圆点和展开按钮。展开后平台图标和收起按钮位于右上侧，与操作按钮共用一排，取消独立标题行。抖音平台标识使用低饱和灰色，不使用红青配色。

面板、按钮和语音预览统一为深色主题，平台图标使用灰色。展开与收起使用面板窗口加号/减号图标，移除箭头。

包含 0.3.44–0.3.46 的日志精简与双平台本地语音识别，实时音频以约 12 秒窗口处理，语音可独立于场控和录制手动启停。依赖本地 whisper-cli、FFmpeg 与 Whisper small 模型；公开包不附带模型。

配置继承上一版，当前录像不受打包影响。录像结束、退出旧后台后启动本版；抖音更新脚本并刷新，视频号重新加载直播页生效。
