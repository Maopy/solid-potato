# 0.5.0：Windows 桌面客户端迁移至 Tauri

- Windows `启动场控.exe` 使用 Tauri 桌面窗口，直接复用现有 Web 中控页；直播间、录制与下载继续使用 Rust 后台。
- 延续原有配置、抖音用户脚本配对及视频号代理机制；新版本目录继承上一版配置，旧版本保留。Windows 需安装 Microsoft Edge WebView2 Runtime，FFmpeg 和 mitmproxy 等外部工具仍需按原方式准备。
- 正常关闭窗口会等待后台停止、录制收尾并恢复系统代理。异常退出沿用原有代理恢复进程。
- 开发环境已在场控和自动发送关闭的观察模式下，分别验证抖音与视频号直播接入、短录制和暂停；未发送公屏消息。该测试不覆盖自动发送功能。
- 原 Windows GPUI 客户端保留在旧版本；macOS 和 Linux 本次不改变原启动方式。本版用户脚本版本更新为 0.5.0；如需更新脚本，可在下载任务页打开安装入口，安装后刷新抖音直播页。
