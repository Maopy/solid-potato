# 0.3.36 独立自动点赞

抖音、视频号的统一面板新增自动点赞开关，独立于场控及录制。抖音默认每自然整 10 分钟操作 200 次；视频号默认每 800 毫秒持续操作。可在各自的 `config/douyin-auto.yml`、`config/wechat-auto.yml` 中修改 likes 配置，详见 `docs/moderation-likes.md` 与 `config/likes.example.yml`。

页面重新加载后默认关闭点赞。抖音自动识别播放器双击控件；视频号首次请用面板“定位点赞按钮”单击原页面点赞控件（定位动作不点赞），再开启。页面隐藏时暂停，恢复最多补一批；操作次数不代表平台实际计数。

统一面板去掉“下载任务”按钮，保留录制状态、暂停及继续。继承上一版所有 config；仅为原本没有 likes 配置的两份自动场控文件补充默认方案，已有 likes 设置不覆盖。

本版需更新抖音用户脚本并启动新后台；视频号重新加载直播页。当前后台和正在录制的任务未被重启或中断，真实点赞与评论未用于测试。请先正常退出旧后台、等待录像收尾，再启动本版。
