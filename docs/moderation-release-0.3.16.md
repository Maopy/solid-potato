# 0.3.16 取消发送确认与确认阻塞

按新的发送策略，点击发送后不再等待输入框清空，也不等待平台评论回显。每条命令只尝试点击一次；点击异常或本机执行结果丢失只记日志，该条不会重试，后续礼物感谢、欢迎、定时文案和关键词回复继续按原有队列与发送间隔处理。不再设置“发送未确认”暂停，不再尝试用回显解除暂停。

保留点击前的直播间和会话绑定、页面状态、输入框与按钮检查、用户正在输入时不覆盖、重复命令去重，以及同一账号的发送限流。平台是否真的展示了评论不再作为继续发送的条件。输入框里仍有内容、正在编辑、按钮不可用等点击前检查仍会阻止这一次操作；程序不会为了发送下一条而清掉用户内容。

本机命令执行回执仍用于去重和日志，回执丢失不会导致再次点击。超时的旧命令记为结果未知，后续新命令仍按正常限流继续。旧版本的 delivery 配置和回显记录接口保留兼容，但新版页面不再启动平台发送确认任务。

完整继承当前运行版本的配置，包括 min_comments、定时文案、昵称映射和关键词设置。本次同时适用于视频号与抖音。

## 使用

1. 正常退出旧版，等待录制收尾和代理恢复，再启动新版。
2. 视频号关闭旧直播页、重新进入并选择任务，加载新的发送脚本。
3. 抖音在统一控制页点击“安装 / 更新抖音场控脚本”，将用户脚本更新到 0.3.16，再刷新直播页。旧抖音脚本里仍有本地暂停逻辑，因此本次需要更新脚本。

启动后场控仍默认关闭，按需开启。不会补发升级前过期或结果未知的文案。
