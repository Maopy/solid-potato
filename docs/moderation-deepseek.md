# DeepSeek 自动回复建议

在中控右上角打开“AI 设置”，输入 DeepSeek API Key 并保存；也可在此替换或删除。密钥保存在本机系统凭据管理器中，软件只显示是否已配置，不回显密钥。保存后立即生效，无需设置环境变量或重启场控。

在中控的直播间面板勾选“自动生成建议”，选择主播、公屏或两者，设置间隔（默认 60 秒，允许 10 至 3600 秒）。间隔保存在当前浏览器中；自动建议每次打开面板默认关闭。公屏只选择最近 15 秒内的留言，主播语音按说完时间计算最近 30 秒，以留出语音识别所需的时间；每次最多发送 6 条近期内容给 DeepSeek。生成完成和点击“采用”时都会重新检查原消息是否过期。生成结果点击“采用”会填入输入框，确认后点击发送，不会自动发送。主播语音需要先开启语音识别。面板关闭或切换到下载页面时不生成建议。

该功能会把选中的主播语音或公屏内容发送到 DeepSeek 云端，并产生 API 费用；模型可能误解上下文或输出不准确的内容，请发送前核对。间隔是每个面板两次请求开始之间的最短时间，失败及模型跳过也计入间隔。密钥仅由场控进程读取，不发送到浏览器。
