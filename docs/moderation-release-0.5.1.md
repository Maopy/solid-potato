# 0.5.1：Windows 桌面窗口退出修复

- 修复 Tauri 客户端关闭时，WebView 窗口尚未销毁就退出应用，导致 WebView2 输出 `Chrome_WidgetWin_0` 错误 1412 的问题。
- 关闭窗口后仍会先等待中控停止、录制收尾和系统代理恢复，再正常关闭桌面窗口；异常退出沿用原有代理恢复机制。
- 新版本独立打包，继承 0.5.0 的本机配置，旧版本保留。需要 Microsoft Edge WebView2 Runtime，FFmpeg 和 mitmproxy 等工具仍按原方式准备。
- 退出修复已在隔离配置和临时代理配置下验证；测试中场控与自动发送关闭，未发送公屏消息。抖音用户脚本的版本标识同步更新至 0.5.1。
