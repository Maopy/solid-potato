# 0.3.76 本地版

- 中控每条公屏留言显示 StartLux 0.8B 的关注分（0–100），越高越值得主播关注。
- 结合该直播间近期主播语音和留言评分，后台完成后原位更新，不改变消息排序。
- 等待或异常会显示实际状态；评分不触发发言、禁言或其他场控动作。
- 抖音兼容缺少旧内容样式类的公屏行，继续保持采集与场控开关独立。
- 中控提示旧版抖音采集脚本需要更新，避免只更新程序而浏览器仍运行旧代码。

使用方法：退出旧版场控后双击本目录「启动场控.cmd」。在中控更新抖音脚本到 0.3.76，
再刷新抖音直播页。视频号刷新直播页即可加载新的采集代码。

此电脑的 StartLux 模型和运行环境已安装在 dist 共享目录，服务已启动。
以后需要时可自动启动。不要单独移动新版本目录，否则会找不到共享模型和配置。
ZIP 不包含模型、密钥或 Python 依赖；复制到其他电脑需要另外安装。
详细信息见「本地留言评分说明.md」。已有直播间和场控配置继承上一版。
