# 0.3.23 抖音平台截断后的通用发送校验

定时文案、关键词回复和礼物感谢共用同一套发送流程。此前长文案被抖音编辑器自动截断后，发送前仍与完整原文比较，导致 input_changed 并停留在输入框。

本版仍完整填入原文，由抖音自动截断，不主动裁剪、不添加省略号。发送校验同时接受完整原文或平台准确保留的前 50 个 UTF-16 单位；其他编辑变化仍拒绝。点击前再次检查当前内容是否一致。所有规则使用同一能力，配置文案不变。

不等待回显、不重试、不补发旧草稿。保留输入占用、页面、时效、场控开关与去重检查。回归测试覆盖真实失败文案、三类规则、平台截断、异常内容变化与重复命令，不连接真实平台发送测试消息。

配置完整继承当前运行版本。更新抖音用户脚本后刷新即可，权限范围不变，可继续使用现有后台，录像无需重启。下次可使用本版启动入口。
