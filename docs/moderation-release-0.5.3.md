# 0.5.3：FunASR 主播声纹筛选

- 移除其他语音识别和声音分类实现；使用 FunASR Paraformer、FSMN-VAD、CT-Transformer 和 CAM++ 声纹模型。
- 本机根据心怡076当天录屏中的发言建立声纹参考，仅对已配置的抖音及视频号直播间启用筛选。其他直播间维持普通识别。
- 过滤会抑制声纹明显不匹配的片段，少于 2 秒的片段保留。无法彻底分离同时出现的主播与歌声，可能漏掉主播或保留歌词；声纹筛选增加处理耗时。
- 本机测试中，一段未参与建档的主播发言保留，两段歌词被过滤；这只是少量样本，需在实际直播中继续验证。声纹参考、模型与环境仅保存在本机共享目录。
- 新版本单独打包，旧版本保留。
