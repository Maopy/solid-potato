# 0.3.11 统一入口与可见场控开关

这次统一的是实际启动流程和控制界面。双击 **启动场控.command** 或运行 `./run.sh`，同时启动抖音和视频号，并自动打开本机“直播助手”控制页。所有旧启动脚本也转到该入口。

统一页显示两个平台的连接状态、场控开关、录制操作和下载任务。两个平台的直播页也有同样的“直播助手”入口。场控启动时默认关闭，连接直播页后按需要开启；录制独立操作，不需要开启场控。

修复前版入口不统一的问题：原 controller 示例指向观察配置，平台启动脚本仍各自启动；抖音录制依赖独立脚本注入。新入口直接引用原 douyin-auto.yml、wechat-auto.yml，抖音录制也随主脚本加载。原 0.3.10 config 完整继承，不改用户文案和开关，新启动配置为 unified.yml。

关闭场控会取消等待回复，关闭期间不积压，重新开启后只处理新互动；不会重新发送已有未确认评论。旧轮询返回不会覆盖更新后的开关，也不会执行旧命令。录制任务的暂停、继续、移除与视频收尾保持独立。

更新前停止旧进程，使用本版统一启动文件，再重新打开直播页。详细配置和“抖音未连接”的检查方法见 [统一入口说明](moderation-unified.md)。验证使用本机模拟与既有 FFmpeg 测试，不向真实直播间发送测试评论。
