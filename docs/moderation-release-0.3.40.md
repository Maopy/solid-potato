# 0.3.40 点赞图标与抖音快捷键

点赞按钮与场控、录制按钮统一为相同的绿色背景、圆角和高度，使用白色拇指图标，旁边小圆点灰色表示关闭、绿色表示开启。悬停提示与读屏标签保留当前状态和操作说明。

抖音通过原页面 Z 快捷键点赞，无需定位控件，面板仅保留点赞开关图标。焦点在评论框、文本编辑区域或 iframe 时暂停点赞，不输入 Z、不改变焦点。

视频号保留并排的拇指和定位准星图标，不使用独立文字按钮。定位中准星变成取消图标。自动识别不到控件时仍可定位。每自然整 10 分钟的批量调度和视频号持续模式保持不变。未在真实直播间执行点赞测试。

配置完整继承上一版。抖音需更新用户脚本并刷新页面；视频号需启动新版后台、重新打开直播页。当前后台及录制任务未自动重启。最高画质录制等此前改动保留。
