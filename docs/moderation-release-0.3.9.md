# 0.3.9 评论关键词回复

新增抖音、视频号评论关键词回复，发送普通评论。此发布包的两个自动发送配置已配置“胎记 → 手臂是胎记”。同一关键词与同一回复文案各自 60 秒最多生成一次，多个关键词共用同一句回复时共享回复冷却，避免密集刷屏。程序自己的回复和旧评论不会重复触发。更多规则见 config/keyword-replies.example.yml 和 docs/moderation-keywords.md。

打包自动继承上一版本的整个 config 目录，保留用户修改与自定义文件；本版只在自动发送配置中添加上述新规则，不改定时文案与欢迎开关。示例片段不会自动执行，需要合并到实际使用的配置。

停止旧程序后使用本版启动脚本；关闭旧直播页、重新打开并开始采集。视频号首轮评论轮询用于建立历史基线，从后续新评论开始触发。无需选择评论或打开回复菜单。沿用原发送限速、暂停和回显确认机制。

验证使用本地模拟，包含关键词共享冷却、60 秒边界、重复消息、自身回复、暂停取消、历史轮询过滤和普通发送队列；未向真实直播间发送测试评论。保留 0.3.8 的礼物回显修复。
