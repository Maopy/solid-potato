# 0.3.71 直播入口与星守护欢迎修复

- 统一场控模式在首批录屏脚本执行前声明，视频号从一开始就不创建旧下载图标、录制按钮及状态栏，避免先显示再移除的闪烁。直播数据采集和统一面板录制功能保留。
- 独立录屏模式继续提供原录制入口。
- Windows 按当前 CA 证书的 SHA-1 指纹检查根信任，避免旧的同名 mitmproxy 证书导致误判。
- 视频号持续点赞默认间隔改为 200 毫秒，约每秒 5 次。本机打包继承已有配置。
- 抖音识别当前主播的原生 `star_guard` 进场标记，恢复星守护“欢迎回家”；核对特效目标用户与粉丝团主播身份，不将昵称文字、普通等级特效识别为星守护，保留原有欢迎冷却。

本机升级：完成当前录制并退出旧后台后，打开新版“启动场控.cmd”，再重新进入视频号直播页；已有缓存可用 Ctrl+F5 刷新。抖音脚本版本同步为 0.3.71。

公开打包内容不含证书私钥、运行数据或语音模型。运行依赖继续使用本机已有安装。
