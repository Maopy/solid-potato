# 0.3.43 点赞时段记录、自动识别与简化面板

按钮统一为同一行绿色文字按钮：“开启/关闭场控”“录制”“点赞”，保留录制及点赞状态圆点。录制的开始、暂停和继续动作通过状态及悬停提示区分。两平台均不再显示定位按钮。

视频号自动匹配已核对的原生 `.controls__ft .cheers__wrp .live-opr__btn` 控件；仅唯一、可见时点击。无须手动定位，不使用截图中的固定坐标。单个场控任务自动绑定，不再显示白色任务选择器；多个候选任务仍保留选择。首次进房及同一直播重连不会误判为换房；确认主播身份变化时才停止旧绑定。

抖音按标签页和直播间记录每个自然时段是否已触发点赞。开启点赞后立即向后台查询并申领当前时段，尚未触发则立刻开始一批，已经触发则等待下一时段；默认仍为自然整 10 分钟每批 200 次。记录存入该房间运行目录的 moderation-probe.sqlite3，刷新页面或重启同一后台目录仍保留。点击开关关闭会取消剩余操作，记录的是批次触发，不表示平台确认收到全部 200 次点赞，也不会因刷新自动补完中断批次。后台不可用时暂停申领，不在页面端绕过去重。

每个页面使用独立连接及点赞开关。两平台在输入框、文本编辑区域或 iframe 获得焦点时暂停点赞，移开焦点后继续；不保存、恢复草稿或强制改变输入焦点。视频号输入和光标稳定性已由实际操作反馈确认；测试未发送评论。

配置完整继承上一版。抖音需更新至本版脚本并刷新页面，视频号需启动本版后台并重新加载直播页。最高画质录制等先前改动保留。记录位于运行数据目录，升级时若切换全新数据目录，已有时段记录需一并保留。
