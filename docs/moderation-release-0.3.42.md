# 0.3.42 统一按钮与视频号自动点赞识别

场控、录制、点赞控件放在统一 flex 工具栏中，对齐按钮高度和间距。点赞显示“点赞”文字，录制固定显示“录制”，保留状态圆点，悬停提示显示开始、暂停或继续动作。视频号定位图标仍与点赞按钮并排。

保留 0.3.41 的视频号自动识别：根据控件语义及直播画面区域识别右下角拇指，不使用固定截图坐标。存在多个候选或未找到可信控件时不点击，定位图标保留作备用。抖音继续使用 Z 快捷键。

两平台在输入框、文本编辑区域或 iframe 获得焦点时暂停自动点赞，移开焦点后继续，不读取、缓存、恢复草稿，也不改变输入焦点。

配置完整继承上一版。抖音更新用户脚本并刷新直播页，视频号启动新版后台并重新打开直播页后生效。
