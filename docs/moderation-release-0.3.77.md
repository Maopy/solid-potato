# 0.3.77 本地版

- 移除中控底部的消息保留条数、当前条数提示，实时跟随时不再留空白底栏。
- 每条公屏留言末尾增加「回复建议」。点击后在该条留言下方展开三个方向：直接回应、互动追问、轻松接话。
- 建议参考点击时同一直播间最近 5 条其他公屏留言、最近 5 句主播发言和当前目标留言；没有主播语音时会明确提示。
- 本地 StartLux 从各方向的话术候选中选择，适用时引用主播原话；当前不是自由生成模型，不能编造未知歌名或其他事实。
- 建议可复制、收起；不会自动发送。请求进行中与失败均有提示，失败可重试，其他消息仍继续采集和评分。
- 两个直播间的上下文、展开状态和建议独立；30 分钟后随留言一起过期。

退出旧版后，双击本目录「启动场控.cmd」。若中控提示脚本版本过旧，更新抖音脚本并刷新直播页。
本机共享模型和配置继续复用，全部直播间配置继承 0.3.76。

StartLux 权重仅允许非商用免费使用，商业用途需要另行授权。模型及运行环境不包含在 ZIP 内。
