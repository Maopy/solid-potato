# 0.3.32 定时文案只按文字评论计数

新增 timed_messages.count_scope: text_comments。抖音与视频号仅统计采集开启后的实时文字评论，包含当前账号及场控自动发送的文字；进场、礼物、关注、点赞、系统提示和等级快照均不增加计数。同一原生评论 ID 去重，历史消息不回算，时间和 min_comments 仍需同时满足。每次生成定时文案后重新计时、计数；没有足够的新文字评论时不发送。

此次排查发现视频号 19:45:06 至 19:46:06 的计数包含 16 条 type=10005 进场通知和 1 条 type=1 文字消息。旧 public_screen 模式按原生消息列表统计，未核对进场是否进入实际评论列表，导致没有新观众文字也达到阈值。根据新的明确要求，两平台本地自动配置切为 text_comments，其他阈值、间隔和文案不变，原配置备份在 dist/.config-backups/2026-10-21-timed-text。

comments 模式仍兼容只统计观众文字且排除场控消息的旧口径；public_screen 保留原行为，不再作为本地自动配置的计数模式。面板会显示“文字评论”和“包含场控消息”。现有浏览器脚本支持该计数分支，新版用户脚本同步更新面板标签。启动新后台后重新加载页面生效。

新增回归覆盖只有大量进场时不发送、场控文字计数、重复评论只计一次、时间到但文字条数不足不发送。当前正在录制的后台不被重启，配置变更在切换本版后台后生效。
