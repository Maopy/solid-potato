# 0.3.20 抖音自动发送控件兼容

抖音部分直播页面的发送按钮是没有文字的 SVG 箭头。此前只查找“发送”文字，导致已生成的回复留在输入框，日志为 send_not_found。本版在当前评论输入区内识别平台的 SVG 发送控件，并派发一次冒泡鼠标点击。

保留按钮唯一性、可见性、输入内容一致性、场控开关、限流和命令去重校验。每条命令仍只尝试一次，不确认回显、不重发。不会清理或补发旧的失败草稿。

sending.automatic: true 时，开启场控即自动发送礼物感谢、关键词回复、定时文案。关闭场控停止自动回复，录制独立。默认收起的面板保持不变。

config 完整继承上一版。抖音需要更新用户脚本并刷新页面；权限范围不变。
