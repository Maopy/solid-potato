# 0.4.23 直播间配置直接同步

- 中控保存欢迎、礼物、定时文案、关键词回复和点赞设置时，直接更新对应平台 YAML 的直播间专属配置；不再创建独立设置文件。
- 手动修改 YAML 后，已连接房间自动重新读取上述互动规则；配置错误时保留原设置并在中控提示。已经进入发送队列的文案不被改写，定时文案条件变化后重新计时和计数。
- 旧版本的 room-overrides.json 在升级打包或启动时合并进 YAML；原版本不受影响。保存前校验配置并检查并发修改，保留未修改部分的注释和其他设置。
- 连接模式、代理、录制目录、账号和发送限额等运行环境设置仍需重启，且不会通过直播间设置界面修改。
- 抖音请从新中控更新用户脚本；真实直播页面需继续现场验收。
