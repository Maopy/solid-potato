# 0.3.13 抖音用户脚本接入

统一入口不变：双击“启动场控.command”。抖音通过 Tampermonkey 用户脚本连接本机程序，视频号继续使用代理。代理只解密视频号相关域名，抖音 HTTPS 连接透传，无需信任场控 CA；浏览器也可以直连抖音。

## 首次安装

1. 安装 Tampermonkey。如果已在使用 LiveBot，通常已经安装；关闭 LiveBot 的自动发送，避免两个场控重复回复。
2. 启动新版，在统一控制页点击“安装 / 更新抖音场控脚本”，在 Tampermonkey 安装页确认安装。
3. 打开任意数字房间地址的抖音直播页并刷新。右上角出现“直播助手 · 抖音”，统一控制页自动列出该房间。
4. 每个房间默认关闭场控，按需开启。录制与场控开关独立，播放直播后可点击“录制直播”。

启动前先在旧程序终端按 Ctrl-C，等待录制收尾和代理恢复。程序重启后刷新抖音直播页重新连接，不恢复旧页面待发送的消息。

安装脚本后，正常重启无需重复安装。脚本更新时再点击安装 / 更新。配对密钥保存在发布目录旁的 `.live-archive-userscript-key`，不是证书；不会打进发布压缩包。保留该文件和端口 2025，后续版本继续使用原脚本的配对信息。移动整个发布目录、删除密钥或修改端口后，需要重新安装脚本。不要分享本机生成的脚本、配对密钥或安装链接。

## 配置与兼容

完整继承上一版 config。旧 unified.yml 如果没有 douyin_userscript 字段，仅追加新接入设置；已有明确设置则保留。原 douyin-auto.yml 作为所有动态抖音房间的规则模板，房间 URL 不再限制用户脚本接入。文案、昵称映射、30 秒合并欢迎、关键词及发送规则仍由本机程序执行。

```yaml
douyin_userscript:
  enabled: true
  port: 2025
  key_file: ../../.live-archive-userscript-key
```

每个抖音直播间独立队列、开关、连接票据和录制请求，同一账号共享发送限流。同一直播间同时打开多个标签页时只允许一个自动发送连接；重复标签页需关闭或刷新。当前支持一个抖音账号/配置模板、最多 32 个动态房间，多个抖音账号应使用不同浏览器和独立实例，不能在一个实例里混用。视频号原来的任务配置与选择方式保留。

脚本在 document-start 同步挂接页面已有网络连接，等待本机启动期间使用有容量上限的临时缓冲，不创建平台 WebSocket、不向平台 socket 写入。所有可执行脚本随安装包提供，不从后端下载代码执行。本机请求只允许固定 API，并校验配对凭证、会话和房间绑定；普通网页不能直接读取接口。

## 排查

- 看不到面板：确认 Tampermonkey 和本脚本已启用、允许在 live.douyin.com 运行；Chrome 若提示允许用户脚本，请按扩展提示开启。安装后必须刷新直播页。
- 显示无法连接本机场控：先启动程序；确认 2025 端口未被占用。
- 显示连接已停止：刷新直播页；同一房间保留一个场控标签页。
- 场控开启后不回复：查看连接、输入框和发送未确认状态；页面改版或消息格式不受支持时会暂停，不能通过反复开关强制重复发送。
- 抖音仍显示旧证书错误：确认已退出旧代理程序，再启动新版。若浏览器代理还指向旧实例，新脚本不能修复旧实例签发的证书。
