# 0.3.27 输入框发送事务

修复抖音自动发送后立即恢复草稿，与页面异步清空输入框发生竞争，以及原草稿为空时未清理临时场控文案的问题。所有自动文案继续使用相同发送通道。

执行器增加串行任务边界：暂存草稿、填入、单次点击、本地编辑器短暂稳定、恢复草稿完成后，下一任务才能使用输入框。队列等待计入原命令有效期，不延长过期任务。发送按钮仍只点击一次，不等待服务端或弹幕回执、不补发。观察本地编辑器最少约 320 毫秒、最多 700 毫秒；有限窗口不能保证任意更晚的页面更新，但可覆盖已添加回归测试的延迟清空。

空草稿也会恢复；发送前按钮不可用等失败路径清理本次写入的临时文案。用户继续打字时，先恢复原草稿再保留新输入，并停止此次后续操作；无关的新文字不被旧快照覆盖。保留光标、输入法和富文本保护。

本版包含 0.3.26 欢迎恢复等改动。本地打包继承上一版配置，不中断现有后台录像。测试在模拟页面执行，未向直播间发送测试弹幕。
