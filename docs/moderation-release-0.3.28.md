# 0.3.28 定时文案按公屏消息计数

新增 timed_messages.count_scope: public_screen，包括场控自动发送的消息。min_comments 与 interval_seconds 仍需同时满足；生成定时文案后重新累计，关闭场控或暂停采集后清零。count_scope: comments 保留原有有效观众文字评论计数，未指定时兼容旧配置。

抖音按公屏列表中新出现的 data-index 行计数，不再与网络评论相加。首次挂载已有行只建立基线；相同行号重复采集、重绘、礼物连击数字更新不重复计数。“鲜花 ×5”一行算一条，不按礼物数量算五条。没有出现在列表中的点赞数字或后台事件不计入。

视频号按已建立序号基线后的原生 msg_list 新条目以及已识别的 20013 礼物展示通知计数，不再只认 type=1。相同原生消息 ID 去重。列表计数不是逐像素 DOM 可见性判断，无法保证与平台折叠、过滤后的可见行严格一致；原生列表之外尚未识别的 UI 提示仍可能漏计，需实播验证。礼物候选修订、诊断事件、等级快照不额外加一。

面板显示“公屏消息”和“包含场控消息”。本地发行版保留上一版配置，仅对定时规则增加 public_screen 计数范围；阈值、间隔、文案等不变。原配置保留在上一版本目录。切换新版后台后重新加载直播页，使脚本与后台都使用新计数范围。不为更新中断现有录制，不补发历史消息。
