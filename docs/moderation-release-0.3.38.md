# 0.3.38 两平台优先最高画质录制

录制固定选择当前直播接口提供的最高可识别画质，不增加配置项。

抖音按原画等画质档位排序，同档比较分辨率及码率。兼容 flv_pull_url、hls_pull_url 和内嵌 stream_data 的清晰度列表。播放中的低清流、候选返回顺序及先前选择不会覆盖较高档位。独立旧录制面板中的清晰度列表仅显示自动选择结果，不能切换到较低档位。

视频号把当前直播原生映射器提供的 cdn_trans_info 传给录制后台，与原生响应中的同类列表统一比较，按画质标签、分辨率和码率选择；不再固定使用默认 liveCdnUrl。未提供其他可比较档位时保留接口提供的默认源流，不拼接或改写签名地址。

录制继续使用 FFmpeg -c copy，不做升频、放大或重新压缩。最高画质取决于平台为当前直播实际提供的源流，并不保证每个直播间都有 1080p 或更高档。

配置完整继承上一版。请正常结束旧版录制、等待文件收尾后启动本版，在控制台“安装 / 更新抖音场控脚本”后刷新抖音直播页，视频号也重新打开直播页。变更在新建录制任务时生效，已有录像无法恢复更多细节。本次测试使用模拟数据与本机测试流，未中断现有录制。
