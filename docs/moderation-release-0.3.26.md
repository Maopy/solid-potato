# 0.3.26 进场欢迎恢复

普通进场欢迎仍按第一位用户起 30 秒收集名单，合并生成一条欢迎；同一用户 60 秒内重复进场不重复欢迎。没有新进场用户不发送，礼物感谢优先。视频号超粉、星守护保持每位用户一分钟一次的独立进场欢迎。

修复抖音当前原生 WebcastMemberMessage 没有 Common.create_time、也没有独立事件时间，导致进场事件全部 live_eligible=false 的问题。对已核对房间身份、action=1 的原生进场通知，使用所在 WebSocket Response 的服务器时间检查实时性；仍拒绝过期、未来或错误房间的消息，显式的旧 Common 时间不会被覆盖。不把本机收到时间当作实时证据。

本地现用及新版本配置中的 rules.welcome 已恢复开启，rules.supporter_welcome 也显式开启。其他个性化配置、定时文案与阈值保留，原配置另行备份。公共源码里的示例配置本来就开启欢迎；打包仍尊重用户已有的开关，不会强制改写用户以后主动关闭的规则。

实际运行中的规则在启动时加载。更新用户脚本后，需在现有录像结束后使用本版后台启动入口并打开场控，欢迎开关才生效；不为更新中断当前录制，不补发历史进场欢迎。包含之前的刷新交接、输入草稿暂存恢复、评论计数及录制地址修复。

抖音的超粉/星守护原生身份字段尚未确认，不猜测粉丝团或消费等级；两种身份的专属欢迎沿用已实现的视频号识别路径。
