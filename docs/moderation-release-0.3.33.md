# 0.3.33 撤回输入草稿暂存恢复

撤掉抖音“缓存用户草稿、覆盖发送、再恢复草稿和光标”的功能。页面 DOM 不能可靠代表 Slate 内部状态，异步清空、重绘和用户编辑会使恢复时机不确定，继续增加延时仍无法保证恢复正确。

自动发送只使用空白且可编辑的输入框。已有文字、输入法正在组词、富文本对象均视为忙碌，保留原内容；空输入框仅保持焦点不阻塞自动发送。队列仍串行执行，排队时间计入命令 TTL，过期不补发。输入框有草稿时后台等待发送条件，超过原队列有效期则丢弃，不能保证用户长期占用输入框时的礼物感谢仍保留。

自动填入到点击发送之间若发生真实用户编辑，先取消本次发送；只在用户编辑应用前清除本次临时填入的文本，用户新输入保留。发送前失败时，仅在内容仍属于本次临时文案时清理，避免失败文案成为下一条的草稿。发送按钮只点击一次；点击后由平台管理输入框，不进行延时清空、草稿恢复或自动重试。已提交仍只代表点击动作，不代表平台确认发送成功；平台异常未清空时下一条等待输入框变空，不覆盖已有内容。

统一发送队列适用于礼物、关键词、欢迎和定时文案。视频号原本没有该草稿交换逻辑，保持其原行为。回归覆盖草稿零写入、用户输入中断、失败临时文案清理、连续排队、延迟清空和排队 TTL。模拟页面测试，不发送真实测试弹幕。

新版脚本与现有后台兼容，更新脚本后重新加载直播页生效。有未发送草稿时先自行保存，避免刷新网页丢失草稿。后台不因本次更新重启，录像不会主动中断。本地包完整继承上一版配置，包含之前的代理恢复、外置录屏和文字计数修复。
