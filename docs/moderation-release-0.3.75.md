# 0.3.75 中控显示主播昵称

- 直播间选择框显示主播昵称，替换难以区分的房间或任务 ID。
- 抖音读取当前直播间的主播资料，视频号读取当前直播资料；无需开启场控或录制，页面接入后自动更新昵称。
- 同名主播用平台与序号区分。暂未取得昵称时显示等待提示，长 ID 不进入直播间选择框。
- 主播昵称只影响显示，直播间隔离、控制和录制仍使用原来的内部绑定。
- 保留 0.3.74 的配套 FireRedVAD 按停顿分段、公屏独立采集和最近 30 分钟记录。

本机版本继承 0.3.74 的全部配置，共用已有模型与工具。退出旧后台后双击“启动场控.cmd”，重新打开或刷新直播页。抖音脚本版本同步为 0.3.75，可通过中控“下载任务”的安装入口更新。
