# 0.3.68 Windows 场控与本地语音

- 提供 Windows x64 发布包，双击“启动场控.cmd”启动；修复浏览器打开、凭据存储、进程清理、代理检测及异常退出后的代理恢复。
- 修复视频号未识别主播时启动失败；启用 `recipient_from_page` 后等待页面提供真实身份。
- 抖音点赞模拟持续按住 Z：首个 keydown 后每 33 毫秒自动连发，批次结束才松开。默认每自然 10 分钟一批 200 次键盘事件，约 6.6 秒；停止、隐藏页面、窗口失焦或编辑输入时释放 Z。次数是页面操作次数，不代表平台确认的点赞数。
- 抖音油猴脚本版本同步为 0.3.68。启动新版后台后，从统一控制台重新安装脚本，再刷新直播页；运行中的旧后台仍提供旧的内置脚本。
- 支持 FireRedASR2S 的 FireRedASR2-AED 本地识别组件，常驻模型、GPU 推理、UTF-8 传输和进程异常诊断。模型、源码及 Python/CUDA 依赖单独安装，不包含在 ZIP 内；本机共享配置沿用 `dist/asr.dev.json`，旧 Whisper 配置保留用于回退。
- 处理 Windows 代理套接字清理阶段的 WinError 10054，确保完成连接关闭，其他异常继续报告。
- 所有改写的视频号页面与脚本禁止缓存，避免关闭场控后继续加载依赖本地代理的旧资源。已缓存的旧页面可用 Ctrl+F5 强制刷新。
- 打包继承上一 Windows 版本的自定义配置，包括录屏目录、房间文案及昵称表；默认不跨系统继承 Mac 路径。

## 本机升级

退出旧后台后，打开本目录的“启动场控.cmd”。本机发布包继承既有配置，录屏路径仍为 `E:/直播录屏`，语音依赖继续共用上级目录下的 `.live-archive-tools` 与 `.live-archive-models`。

若旧后台仍在录制，可先完成录制再退出；解压或打包新版不会切换正在运行的后台。视频号重新进入直播页，抖音重新安装 0.3.68 油猴脚本并刷新。
