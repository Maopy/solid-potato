# 0.3.45 直播语音识别

统一面板新增“语音”开关，独立于场控、录制和点赞。默认关闭，打开后使用当前直播页已经提供的流地址，在本机提取音频并调用 whisper.cpp 中文模型。无须先录制，也不会发送评论。

展开面板显示识别状态和最近最多 6 句。仅保留当前页面会话中的少量文字，关闭、刷新、换房、会话过期和后台退出时清空，不写转写历史、字幕或数据库。识别期间使用的短时音频及模型结果放在临时目录，处理完成或正常取消后删除；不向第三方识别服务上传音频。

每约 12 秒音频识别一次，加上推理时间后更新，并非逐字即时字幕。短语会按标点整理；句子跨音频边界时可能不完整。静音跳过。全后台最多同时执行一个模型推理，处理不及时只取最新音频，不积攒历史队列。直播结束或连接中断后显示原因，需重新开启；暂留当前最近几句，关闭即清空。

本地开发环境继续复用仓库根目录的 asr.dev.json、已安装的 whisper-cli、FFmpeg 和 dist/.live-archive-models/ggml-small.bin。也可用 LIVE_ARCHIVE_ASR_CONFIG 指定配置文件。模型不随版本包重复复制；公开分发包不自带模型。没有模型或引擎时仅语音识别显示错误，不影响其他功能。

包含 0.3.44 的日常日志精简。配置完整继承上一版。请在录像结束并退出旧后台后启动本版；抖音需更新本版用户脚本并刷新直播页，视频号重新加载直播页。不要同时启动两版后台。
