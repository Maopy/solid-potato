# 评论关键词自动回复

抖音、视频号的新评论包含关键词时，通过原有队列发送普通评论，不操作原生“回复某人”。需要自动发送模式。将 config/keyword-replies.example.yml 中的配置合并到实际启动的房间 YAML，重启程序并重新打开直播页加载新脚本。

```yaml
keyword_replies:
  enabled: true
  cooldown_seconds: 60
  rules:
    - keywords: ['胎记']
      reply: '手臂是胎记'
      match_mode: contains
```

默认包含匹配，不区分英文字母大小写；exact 为全文匹配。每条规则可配置多个关键词，也允许不同规则共用同一回复。关键词与回复文案分别冷却：任意一项仍在 60 秒内，就不生成回复。第一条匹配规则决定结果，冷却期间不改用后面的规则。冷却从生成草稿开始，等待期间的新命中不积攒补发。

过滤已知程序发送的文案、已配置回复原文及配置的发送者账号，避免回复循环。重复原生消息不会重新触发。视频号只从成功的服务器评论轮询中取新序号，首轮建立基线，恢复采集后重新建立基线；没有可靠序号时不触发。抖音要求带有效近期时间的解码消息。超出长度或包含控制字符的评论不触发。

发送与礼物感谢、欢迎和定时文案共用输入框、限速与未确认暂停机制，可能因队列繁忙而延后或过期，不保证精确到秒。输入框不可用或发送结果未确认时不绕过保护，不自动重发。日志中的 keyword_reply_draft 表示已排队，不表示已发送；发送结果看 fill_audits。视频号面板展示关键词回复状态。

最多 32 条规则，每条 16 个不重复关键词，关键词最多 64 字，回复受房间文本长度限制且最多 80 字。默认关闭；发送开关及实际配置仍由房间 YAML 决定。
