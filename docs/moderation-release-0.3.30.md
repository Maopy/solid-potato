# 0.3.30 主播目录与统一录像文件名

抖音、视频号的集成录制统一保存到“输出目录 / 平台 / 主播名”，同一主播不同场次直接放到相同目录，不再使用任务 UUID 目录。保留平台层，避免两平台同名主播混在一起。默认仍为系统下载文件夹/直播录屏，自定义 output_dir 和其余配置不变。

文件名统一为 yyyy-mm-dd-hh-mm-ss-编号.mp4，例如 2026-10-21-19-30-00-000.mp4。日期时间为本机开始该轮录制的时间，编号从 000 起，TS 中间分段也使用同样格式。同秒重新开始时续用该秒已有的最大编号，不覆盖已有 TS、MP4 或未完成 MP4。旧命名的中断 TS 仍能按原格式恢复。

抖音优先读取已识别房间元数据中的主播昵称；回退页面标题时去掉已知“的抖音直播间 - 抖音直播”后缀。后台也处理旧脚本上报的同类标题，因此旧脚本仍能使用新目录规则。文件夹名替换路径分隔符、控制字符等，限制长度并防止空名字或点路径。

主播目录增加内核占用锁，避免共享目录后另一任务将仍在写入的 TS 当成中断文件处理。已有录制占用时提示，不并行写入同一主播目录；隐藏 .recording.lock 保留，进程退出自动释放锁。同平台重名主播会共用目录并受同一锁保护。

不移动或重命名旧视频，不中断当前录制。新后台启动后的新录制使用新规则。已继承上一版配置；本版脚本仅改进昵称获取，刷新后使用。
