# 0.3.29 录屏保存目录外置

场控集成录制的默认媒体目录改为系统“下载”文件夹下的“直播录屏”（macOS 通常是 ~/Downloads/直播录屏）。抖音、视频号共用该设置，仍按平台和任务分子目录，文件名保留主播与时间。默认目录不再依赖场控版本目录。

统一入口编辑 config/unified.yml 顶层 recording.output_dir；null 或不填写使用系统下载文件夹，自定义请填写绝对路径，例如 /Volumes/Media/直播录屏。controller 使用自身顶层配置，单房间使用房间 YAML。相对路径仍相对于 YAML 目录解析。已有自定义路径不改写，新版本继续继承上一版本配置。

打包时仅为没有 recording 配置的 unified/controller 添加可见的 output_dir: null 配置，已有录制开关、分段时长、FFmpeg 与目录均保留。系统下载目录无法查询时使用用户主目录下 Downloads；无法取得用户目录时明确报错，不再回落到版本目录。

升级只影响新启动的录制；不搬迁旧文件，也不停止、移动正在录制的文件。删除旧版本前需先移出旧目录里的视频。任务数据库和日志仍在场控数据目录，不影响外置媒体文件保存。现有 0.3.28 浏览器脚本可继续使用，无需更新脚本。
