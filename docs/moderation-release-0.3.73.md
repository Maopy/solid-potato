# 0.3.73 公屏采集独立于场控

- 中控模式下，直播页接入后自动采集公屏，无需开启场控。关闭场控后，抖音和视频号的留言继续进入中控时间线。
- 场控开关继续控制自动回复、欢迎、礼物感谢等动作。关闭期间的留言只作展示，开启后不会补发这些留言的自动回复。
- 抖音在未启用规则预览的中控模式下也加载公屏解码器；视频号切换场控不会重新建立公屏历史水位。
- 页面离开当前直播间或后台退出时，公屏采集仍会正常停止。独立诊断模式保留原来的手动采集入口。
- 保留 0.3.72 的双直播间混排、紧凑布局、绿色声波图标和最近 30 分钟记录。

本机版本继承 0.3.72 全部配置，共用 dist 下现有语音模型和工具。退出旧后台后双击“启动场控.cmd”，重新打开或刷新直播页。抖音用户脚本版本同步为 0.3.73，可通过中控“下载任务”中的安装入口更新。
