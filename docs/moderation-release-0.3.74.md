# 0.3.74 按说话停顿分段与配套声音分类

- 取消固定 12 秒的语音识别窗口，改为检测说话停顿约 600 毫秒后送去识别。短暂犹豫不切段，连续讲话以 10 秒为兜底上限。
- 接入 FireRedVAD/AED 配套声音分类模型，只取说话标签；没有讲话的纯音乐、唱歌时段不送去转写。同一时刻有说话和音乐时保留讲话，避免因音乐标签漏掉主播。
- 语音时间以最后讲话帧为准，不包含等待停顿、分类或识别耗时。识别结果仍补回对应时间位置。
- 保留起音前少量音频和收尾，处理音频传输块交界与直播结束时的最后一句；句子按顺序排队，替换原来只保留最新窗口的方式。
- 保留 0.3.73 的公屏独立采集、双直播间显示和最近 30 分钟记录。

本机已下载并校验约 2.3 MB 的 FireRedVAD/AED 权重，继续共用 dist 下的模型与工具环境。原配置已继承，无需修改。退出旧后台后双击“启动场控.cmd”，重新打开直播页并开启语音。

这是说话/唱歌/音乐分类，不是人声分离或伴奏消除。配套模型约有 1.5 秒前瞻，再加停顿确认和识别，结果通常会晚几秒出现；首次加载主识别模型更慢。背景歌词与主播讲话重叠时仍可能影响转写，停顿也不一定是语义上的完整一句。

详见 Windows使用说明.md 中“按句分段与声音分类”。模型、证书、运行数据不放入本地 ZIP；本机共享依赖已准备好。
