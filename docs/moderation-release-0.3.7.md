# 0.3.7 视频号神秘观众昵称修复

修复视频号礼物感谢中神秘观众被称作 `***` 的问题。原始消息的普通昵称为 `***`，公开编号来自发送者 `badge_infos` 中类型为 10 的徽章，例如 `神秘观众 179`。现在感谢中使用 `神秘观众179`，不使用用户 ID 推算编号。

仅在普通昵称为 `***` 且徽章名称完整匹配“神秘观众 + 数字”时替换。缺少编号或徽章不匹配时保留原昵称，普通观众不受影响。完整用户 ID、礼物去重、按用户聚合和原始消息存储保持原有行为；昵称映射表中的专属昵称仍优先。

## 更新

停止旧场控，使用本版本二进制启动。可以继续通过 `--config` 指向现有 YAML，保留原有配置和数据目录。关闭旧直播页面再重新打开，并开始采集，以加载新注入脚本。无需新增配置。

本版本包含 0.3.4 的发送确认修复、0.3.5 的昵称映射及 0.3.6 的定时随机文案。仍在使用 0.3.3 的用户需要替换启动的二进制，单纯重启旧版本不会获得修复。

## 验证

使用本地集成链路验证原生消息注入、HTTP 传输、日志持久化、礼物合并及感谢输入框。覆盖带空格和不带空格的神秘观众编号、普通昵称、错误徽章类型、异常徽章及缺少编号。测试不向真实直播间发送消息。

定时文案配置参见 [0.3.6 使用说明](moderation-release-0.3.6.md)。
