# 0.3.72 中控实时内容

- 中控支持同屏查看两个直播间，也可切换单间；每个窗口顶部独立选择直播间。
- 主播语音和公屏留言按时间混排。语音采用浅绿色背景，开头显示“主播”和无底色的绿色声波图标，与正文同行；时间以说完时间为准。
- 顶部控制区和消息间距压紧，增加同屏可见内容。
- 每个直播间保留最近 30 分钟的记录，超时自动清理，不再限制为 2000 条。语音识别晚到时补回对应结束时间。
- 两个直播间独立搜索、筛选与回看。向上滚动暂停跟随，新增内容通过“回到实时”提示；回看中也会清理过期记录。

本机版本继承 0.3.71 的全部配置，继续共用 dist 下已有语音模型、语音配置和工具环境。录屏保存路径、场控文案等保留原配置。

启动：双击本目录的“启动场控.cmd”。重新打开或刷新直播页以加载新面板；抖音用户脚本版本同步为 0.3.72，可在中控“下载任务”中安装或更新脚本。中控内的 30 分钟记录保存在当前后台内存中，退出后台后清空。

语音按约 12 秒音频片段的结束时间定位，受直播播放缓冲影响，不是逐字时间戳。公屏采集覆盖沿用现有适配器。更多说明见 docs/moderation-timeline.md。

包含 0.3.71 的直播入口、Windows 证书和星守护欢迎修复。本地压缩包不包含证书私钥、历史运行数据或模型权重。
