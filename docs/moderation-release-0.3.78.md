# 0.3.78 本地版

- 公屏留言末尾的文字入口改为紧凑的绿色 AI 图标，悬停显示「AI 回复建议」，点击展开或收起。
- 回复建议先单独判断本条留言的意图，再从近期公屏和主播发言中最多选择一条直接相关的辅助信息。
- 问候和夸赞使用对应话术，不引入旁边正在聊的歌曲、舞蹈等话题；移除了引导回复其他观众话题的候选。
- 本条留言保留完整文本；辅助信息仍从同房间近 5 条其他留言和近 5 句主播发言中筛选。
- 仍提供直接回应、互动追问、轻松接话三个方向，支持复制，由用户决定如何使用。

退出旧版后双击「启动场控.cmd」。配置继承 0.3.77，本机 StartLux 模型与运行环境继续复用。
如果中控提示抖音脚本版本过旧，按提示更新并刷新直播页。
